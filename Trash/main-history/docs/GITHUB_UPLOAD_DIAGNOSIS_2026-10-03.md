## 上传路径与当前限制

GitHub 普通 Git 阻止超过 100 MiB 的单文件，因此该 SQLite 不能用直接 `git add` + `push` 的方式交付。Git LFS 已在本机安装（3.7.1），可以选择只跟踪指定 `.sqlite`；另一种方式是 GitHub Release 中附上批次数据包和 manifest。两种方式都不会把数据库暴露给前端；当前前端整库下载入口继续关闭。

参考：[GitHub 文件大小限制](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)、[Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage)。

远端 Git 读取成功；仓库可见性查询因未认证 GitHub API 限流、网页读取失败而未确认。不能把它默认视为私有库。上传企业库与个人备份前，应明确该仓库可见性以及用户希望上传的具体数据组。本轮仍停在诊断阶段，没有创建 LFS 配置、改变忽略规则或上传文件。
