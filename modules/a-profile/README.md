# A｜人格倾向、职业兴趣与求职需求 · v0.5

A整理自报人格倾向、职业兴趣、求职需求和现实条件，不评估能力或岗位胜任力。所有代码在 `modules/a-profile/`；开发分支为 `feat/a-profile`。

## 启动

Node.js 22+，在本目录执行：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:3100/demo/a 。公开代码默认提供30题兴趣英文原题及20题人格中文初稿；不会自动加载本机私有兴趣译稿。

本人本机已有 `.translation-drafts/onet-mini-ip.zh-CN.private-draft.json` 时，可以显式启动私有中文审校：

```sh
npm run start:review
```

此模式只监听127.0.0.1，需本机会话Cookie；30题和20题都以中文呈现，英文原文折叠保留。缺少私有稿会启动失败，不生成或下载替代题。译稿不提交Git，不开放文件下载路径，不作为公开中文版发布。私有V2导出带审校用途及翻译版本标记，拒绝丢失语言信息的v1降级。

O*NET内容修改版公开发布所需的验证研究尚未完成。私有审校依据CC BY-ND §2(a)(1)(B)允许制作、复制但不公开分享适配材料，不以免责声明替代公开发布条件。

## 当前输入与数据

- 完整保留30题职业兴趣与20题人格；两套原始英文JSON和两份计分实现逐字节不变。
- 价值偏好选择优先组；取舍选择预设声明；目标、阶段、城市、最低固定月薪及接受条件均用选择控件。不新增量表维度，不把选择表单冒称工作价值观量表。
- 页面没有自定义价值、取舍、目标、薪资数字填写或“其他条件”自由输入；服务端拒绝选项外的写入和导入。保留未知、本人确认及软/硬要求。
- `SelectionSnapshot`是A导出包装中的确定性选项编码，版本为 `a-choice-catalog-20261002-1`。原ProfileBundleV2和SearchIntentV2字段未改，不生成统一需求分。
- 原始答案与画像保存到Git忽略的 `.data/state.json`，不自动发送给模型。本地Cookie隔离不是生产账户认证。
