# A模块复审与修改方案（待审核的测评替换）

## 结论

当前是有真实本地后端的业务原型，但不是已验证的职业测评产品。48题及计分来自此前编码代理自编，不能沿用任何成熟量表的信效度。此次不替换题库或改公共1.0.0契约；先给出候选工具、影响与实施顺序。修改仍限定A。

## 一、当前差距

| 环节 | 实際情况 | 差距与判断 |
| --- | --- | --- |
| 问卷 | 48题、13维度、1–5符合程度、null | 没有量表题号、中文验证、常模或原题许可链；不能声称测评有效 |
| 计分 | 服务端均值归一0–100，覆盖不足75%未知，35/65分界 | 软件计算可重复，阈值是原型假设；重复性不等于效度 |
| 可读画像 | 分数条、覆盖、模板解释、纠正框 | 缺少每维度来源与更清楚的分组；纠正仅内部保存，C无法得到此说明 |
| 经历 | 6项自由文本：学历、专业、技能、经历、目标、画像纠正 | 无简历上传、解析或OCR；容易重复填写简历内容，目标和纠正不应强制填写 |
| 条件 | 5项各填值、强度、确认 | 可未知、已确认才进入筛选；操作繁琐、摘要出现英文key |
| 数据 | 文件持久化、随机会话、版本快照、导入导出 | 单进程演示，没有生产账号、数据库事务、会话寿命/注销/删除机制 |

逐题台账 docs/ITEM_PROVENANCE.json：48行，每行包含当前题目/维度、原工具/版本/题号/URL（全部null）、自编中文状态、原型计分、许可状态、验证状态。不因题干类似就推定来自O*NET或SDS。

内容复核：q01–q18兴趣每维度仅3道广义偏好题，不是完整活动题量表；q19–q28价值只覆盖成长与稳定，不能代表薪酬、公平、意义、人际等完整结构；q29–q36自主和协作不是互斥两端；q37–q40混合工时、城市、品牌与成长，不能据此判定一个统一生活边界特质；q41–q44混合企业规模、探索、自主和任务新颖性；q45–q48混合组织阶段、收入波动与项目不确定性，不能推导具体接受条件。以上是题意与结构审查，不是统计验证。

## 二、候选工具与证据

### 兴趣：优先评估完整30题Mini-IP的中文适配路线

[O*NET官方工具入口](https://www.onetcenter.org/IP.html)提供30题Mini-IP和60题Short Form。30题每RIASEC维度5题，适合负担受限的A流程；60题每维度10题，不能通过任意删一半生成30题。

[2016原始开发报告](https://www.onetcenter.org/dl_files/Mini-IP.pdf)：开发样本1061，另一个美国验证样本575；Mini-IP各维度alpha为.70–.75（开发）及.74–.81（验证）；有结构和收敛相关证据。与60题对照部分存在同题重叠，不能当完全独立的外部效标，也不代表职业成功预测。统计属于原始版本与样本。

报告的电脑0–4编码按维度加总，Mini范围0–20；[现行API题目文档](https://services.onetcenter.org/reference/mnm/ip/ip_questions_30)使用1–5编码，必须按所选冻结版本核对结果接口，不能混淆20/25上限。原工具Unsure是有数值的中间回答，与当前null缺答含义不同；“未了解/跳过”应另记缺失，不能套当前75%均值补齐规则。保留原始分和计分版本；展示归一分不能叫百分位。不要保留当前35/65分类阈值。

当前未找到可核查的、与拟使用题本一致的简体中文Mini-IP目标求职人群验证研究。这不是断言不存在。官方英语/西语供给不证明中文有效。中文适配须题目级记录、双语审校/回译、认知访谈和目标样本研究；仍未验证时不得标validated。

[工具许可](https://www.onetcenter.org/license_tools.html)与[Developer License §3(b)](https://www.onetcenter.org/license_toolsdev.html)：逐字复用和改编是不同路线。中文翻译/删改不能当作逐字不改；内容改编须验证并明确修改、来源和未获官方背书声明。不能将“网页免费”理解成任意中文改编即可商业上线。此次没有复制新题本、接受条款或联系机构。

### 中文兴趣证据更贴近的备选

- PGI-Short：[Tracey 2010原始开发研究](https://doi.org/10.1016/j.jvb.2009.06.007)，40个活动分别评兴趣和自报胜任，共80个评价。其自报胜任也不是实际能力。[Zhang等2013中文研究](https://doi.org/10.1016/j.jvb.2013.03.009)涉及2567名高中/大学生，报告结构、内部一致性及重测证据。需要取得研究对应的中文题本、精确计分和商业许可；不能只拿RIASEC理论或擅自取兴趣半表就声称沿用完整研究结论。已就业成年人仍需另评适用性。
- [Li等中文VIS原始研究](https://doi.org/10.1017/prp.2017.26)：54个内容题+4个重复题，9维度，研究包含EFA/CFA、重测与同时效度证据。中文大学生更贴近，但题数较多、与6维RIASEC不完全对应；须获取对应题本与使用许可，不能压成48题。

如果产品要求首发即有直接中文目标人群证据，优先取得PGI-S/VIS授权材料再决定，而不是给Mini-IP翻译版贴validated。此次推荐Mini-IP仅是低负担研发路线，不是宣布已有中文版可上线。

### 价值观：20卡排序可作可选深入步骤

[CareerOneStop官方帮助](https://cloudfront.careeronestop.org/Toolkit/Careers/work-values-matcher-help.aspx)：20个陈述、六类价值、相对重要性卡片排序。只使用其自我探索部分，不接其职业匹配。排序不是20道独立Likert题，不能用当前均值算法。

[WIL原始报告](https://www.onetcenter.org/dl_files/DevWIL.pdf)指出重测证据与内部一致性证据不一致，涉及ipsative相对排序的特点；不能简单称全部信度很高。[O*NET现状](https://www.onetcenter.org/WIL.html)：WIL已于2024-06-03退役，保留档案；CareerOneStop的现行工具仍可核查，但题目、翻译、算法与许可需要分别落实。没有找到对应中文20卡版本的目标人群验证，不外推中文效度。

[Zhang等WVM原始研究](https://doi.org/10.1177/10690727251338255)（2025在线发表、2026卷期）直接研究中文大学生：10因素，多研究支持信度/效度。可读公开摘要尚不足以核实题数、完整题本、精确公式和商业许可，保持待核实，不由10因素猜题数。香港WVI中文研究也存在42/45题版本差异，不能混用。

### 工作方式与取舍

[Morgeson & Humphrey WDQ原始研究](https://www.morgeson.com/downloads/morgeson_humphrey_2006.pdf)研究现职工作的设计与特征（540名任职者、243种工作），不是无经历求职者的工作偏好。不能把题干改成“我喜欢”后直接套用效度。暂不增加人格量表。

建议采用少量直接选择：自主/协作、流程/探索、节奏与沟通方式，允许同时喜欢、看情境、未知；标用户自报偏好而非心理维度分数。取舍采用用户主动排序或确认，避免将几种不同条件合成risk/balance分数。这些是产品需求问题，题数和完成效果需要用户测试，不称成熟量表。

## 三、两种画像共用一个事实底座

服务端一次计算AssessmentResult，包含工具/题库/计分版本、题目依据、维度原始分、展示分与覆盖、缺失原因和验证状态。可读Portrait和公共UserProfile均由该结果派生。AI若接入仅接收冻结结果与经确认材料；输出需逐段对应依据，不改变分数，不生成能力、概率、经历或硬约束。

可读画像分兴趣、价值、工作方式、取舍、未知；显示“来自测评”或“你主动选择”，并给出来源与限制。现实条件单独确认，不根据测评自动填hard。相同确认版本必须同时决定用户摘要与后续JSON。

此次兼容修复已为服务端结果增加内部portrait结构，逐维引用现有scores/coverage，并保存新版本答案快照；没有改公共对象字段，也没有更换旧计分。用户纠正向C传递的方案仍待审核：可明确标注用户说明写入现有interpretation，或下述契约升级。

## 四、精简用户流程提案

1. 引导与隐私：选择上传简历或无简历；解释处理范围。
2. 完整兴趣工具：保存/恢复，允许暂停；缺答按选定工具规定处理，不自创补分。
3. 可读画像：兴趣+未知；价值20卡可选深入；工作方式少量选择，不再重复问卷同义项。
4. 经历确认：上传结果在服务端提取，页面仅确认/修正；无简历则最小手填学历、技能及一条主要经历，均可未知。目标/纠正合并为可选补充，不要求重抄完整简历。
5. 行业 → 岗位：多选、简单说明、未知可继续；不从兴趣自动排除选项。
6. 现实条件：城市、固定月薪、销售KPI/出差/外包用工；普通偏好简洁选择，只有声明硬要求时明确确认，最终摘要统一核对。
7. 确认与导出：不可变UserProfile/SearchIntent，修订保留旧版。

简历技术顺序：PDF文本层、DOCX段落/表格 → 检测缺文字页 → 页面/图片OCR → 结构化字段提取 → 逐项确认。必须保留原文定位、页码/段落、提取方法和待确认状态；找不到为null/缺失，不用模型猜学校或经历。扫描PDF与混合PDF按页识别，避免对所有文件强制OCR。只追问影响当前搜索/分析的缺失学历、技能或意向条件。语音不是本轮必需。

上传/解析均经过服务器，检查大小、类型与内容，不保留客户端提供的路径；外部模型前去联系方式且用户知情，密钥仅服务器环境变量。原始简历留存范围/删除策略、OCR本地或云、模型供应商和实际预算在接入时明确。当前没有任何这些服务已接入的宣称。

## 五、后端事实与优先顺序

真实后端：src/server.mjs HTTP；questionnaire.mjs在服务端计分；service.mjs保存答案/草稿/不可变画像/意向；.data/state.json落盘并重启恢复。代码没有模型请求、模型密钥、PDF/DOCX/OCR依赖。profiles/extract真实返回503，不是完成的解析接口。

已有输入校验、HttpOnly同站会话、归属检查、JSON错误、409与导出引用检查；身份只相当于本地浏览器访问能力，不能承诺生产多用户安全。账号登录、会话过期/注销、可靠事务、数据删除/备份、并发数据库访问、提取审计与外部超时/费用都未完成。

修改顺序：

1. 本次兼容性修复：空值hard拒绝、过滤与画像一致、已确认条件不得遗漏、重复确认409、题库版本不支持拒绝重算、中文分块解码、按钮防重复与输入暂存。新增新版本答案快照；老快照不伪造补全。
2. 审核兴趣工具/中文适配/许可路线和语义版本；旧题库只保留历史追溯，不能将旧分数重新贴为成熟工具结果。
3. 实现可读画像与规则输出共用完整AssessmentResult、逐题依据与单工具评分适配；接完整原题而非AI自由出题。
4. 服务端PDF/DOCX提取、待确认字段、最小表单；再接OCR；模型作为受控抽取适配器，先不假设供应商接通。
5. 账号/runtime、事务存储与确认+意向原子提交；增加上传/解析失败、待确认不能生效、版本/归属、结构化输出测试。
6. 目标用户认知访谈、翻译可理解性与完成率/耗时试测；研究设计中评估信度、结构/收敛/区分效度与群体适用性，实际样本不足不报validated。

## 六、需要用户审核的影响

- 替换48题为完整30题Mini-IP中文研发版（许可与验证前不得正式声称有效），或先取得中文PGI-S/VIS材料；会改变题数、题本、计分和instrumentId/version。原答题记录不迁移成新工具答案。
- 价值观是否采用完整20卡可选步骤；仍需对应许可和中文验证，不能混成30+若干题的统一分数。
- 工作方式/取舍从分数改成自报选择；将不再产出原growth/stability/autonomy/balance/risk等旧量表分数，C需按工具版本解释，不能套旧阈值。
- 1.0.0 scores可容纳新键，结构未必需要变化，但含义必须约定；单assessment对象难表达多工具各自版本/验证/覆盖。建议后续公共1.1候选增加instruments列表、各工具scoringVersion/evidence/missing及确认偏好来源，需ABC共同审核，不在此次改字段。若保持1.0.0，完整依据留A内部，单一instrumentId为版本化组合清单，公开validation保守prototype。

尚待用户选择测评路线；其余兼容修复已进行。此次复审和回归测试不等于心理测量验证、简历服务接通或整体联调通过。
