## 已接入

- 指定企业 SQLite 副本及导入清单已通过 LFS / Git 同步，数量不证明质量。
- MiniMax 官方工具调用已接入并实际调用过；实际密钥仅在本机配置。
- Franklin 经受限适配器调查所选公司和关注主题，新材料写独立工作库；次数、时间、输出量及缓存均有限制。
- C 保留出处、范围、日期和核验状态，解释缺失、冲突及岗位适用性。
- 最新接入有实际浏览器 B→C、集成回归、Agent 边界检查与构建记录；不构成独立企业核验。

## 保留的决定

- A 已认可 UI 与填写流程，全部城市和职业方向保留。
- 首页保留“开始新的判断”“继续上次的判断”。
- 真实入口不混入演示、JD 重填或原始 JSON 输入。
- 展示案例改为万科企业股份有限公司 2024 年报告期的风险对照（2026-10-04）。两份官方报告覆盖全部七板块，附印刷页码与 PDF 页链接；并列呈现员工制度与经营压力，示例需求明确标注。集团制度、人数与财务统计不等于岗位兑现，不对应当前在招岗位。
- B 的薪资统计参考可勾选分析，支持参考单独分析与岗位／参考混选，合计最多三条。C 明确保留统计参考类型；统计均值与分布不当作岗位固定月薪，统计记录不提供招聘岗位、城市或在招承诺。
- 用户下载、导出和整库数据包关闭。
- “补充核验回复”板块、入口、页面及 GET/POST 接口已删除；已有核验记录保留在历史归档数据中。
- 会话、侧写、旧报告、历史版本和此前八项黑箱修复保留，撤回功能不恢复。

## 待完成

正式账户、多用户生产隔离、共享生产数据库及无服务器持久任务队列尚未完成。主体关系、在招、薪资、福利与工时等仍需现实核验；公开来源可能为空、被限制或只有摘要，不能承诺七板块资料齐全。

B、C 网页沿用 A 的暖白背景、深绿按钮和圆角白卡。B 清楚显示岗位选择与分析进度，C 统一七板块的需求、资料和判断；长来源详情可展开。A 页面与填写流程保留，分析规则和旧快照不因样式调整而改写。
