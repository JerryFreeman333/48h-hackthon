# C 七板块对照报告

用户审核通过的结构：公司与岗位概况 → 用户需求摘要 → 七板块对照 → 综合结论与下一步 → 折叠来源与补充资料。A 界面与 B 候选流程不改变；城市、方向等保留为筛选和现实条件。

## 实现

- `packages/integration/sector-report.ts`：独立、可冻结的分析模型，版本 `c-sector-report-20261003-1`。每份岗位固定输出晋升与成长、薪酬透明、工时与休息、五险一金、团队文化与工作方式、职位与用工稳定、企业经营状况。每块包含用户需求、已有记载、对照结论和来源。
- 从 A 的已确认优先级、关注方向和现实条件浓缩需求，不从题目选择推断个人每天可接受几小时。B 的本岗位及公司/集团线索分别保留适用范围；其他岗位资料拒用。资料不足、争议、硬条件差异不混成一个未知状态。
- 有培训不推出晋升容易，不打卡不推出八小时双休，六险一金评价不冒充当前岗位承诺，历史亏损不推出当前岗位必然不稳定。公司主体字段冲突在概况提示、补充资料解释。
- 28 项明细和原岗位文本保存在原有调查/证据模型中，默认折叠；主报告每候选最多三个优先核实问题。完整 JD、无销售 KPI 的明确声明继续可查，公共下载保持关闭。
- `demo-flow.ts` 在新报告归档中冻结 `sectorAnalysis`；需求修订、比较和补充回复从冻结资料生成新的报告。旧归档无此字段时保持原报告结构与记录，不覆盖快照。底层五维约束规则保留为硬条件守门及旧报告兼容，主报告使用七板块模型。
- `render-html.ts` 只导出既有 CSS，沿用已认可的报告样式、键盘导航和响应式规则。
