# 现有 A 需求细化：实现与验收

日期：2026-10-13。范围：A 输出用户需求侧写，B 找职位，C 调查所选职位及企业。本轮细化原 `/profile`，没有新增独立产品模块、测评入口或人格分。

## 已实现

- 原七主题、28 个调查明细、21 个基础选择保留；同一主题内按关注事项展开 36 道原创具体追问，其中 8 道需父题条件成立才出现。不要求答完所有题。
- 每项具体选择分别记录“必须满足／偏好／先了解／接受标准未知”。未明确与“没有特别偏好”分开；后者不生成门槛。福利偏好不能豁免适用保障义务。
- 浮动收入、试用报酬差异、阶段结算、轮班、额外工作、下班响应、自主安排、项目结束都有条件分支。父题反改后子答案退出有效侧写，保留最新失活记录；重新选回不会自动恢复旧底线。
- 改变已选安排后接受标准回到未知，需本人重新选择。自动保存、返回、真实服务重启、逐主题修改、本人确认及不可变历史版本可用。
- 同一页面的行业方向扩至覆盖国民经济 A–T 二十大门类的 19 个宽标签，岗位方向 19 类。原七行业和九岗位的 ID、名称、映射及版本保持。它们只提供候选线索，不判断执业资格或能力。
- B 的方向匹配补上新增标签，展示 A 的具体需求；C 的现有关注事项区域展示原选择及强度，并保留“尚未对照判定是否满足”。具体 must 未决时阻止直接建议继续，仍沿用最多三条关键追问的规则。

## 同一需求如何传递

| A 主题 | 具体安排例子 | B/C 交接 |
|---|---|---|
| 成长 | 专业／管理路径、带教、学习时间 | 原 promotion / learning / path / pay_growth 明细 |
| 薪资与兑现 | 固定与浮动、阶段差异、结算约定 | 原 fixed / formula / probation / payment 明细；最低税前固定月薪仍由原现实条件独立确认 |
| 工时休息 | 白天／轮班、加班条件、休息、响应范围 | 原 schedule / overtime / rest / after_hours 明细 |
| 保障 | 适用项目、缴纳口径、起始、本人查询 | 原 coverage / basis / start / verification 明细 |
| 团队方式 | 沟通、自主边界、尊重、评价、协作支持 | 原 communication / respect / evaluation / collaboration 明细 |
| 企业经营 | 主营业务、公开财务、重组影响、履约记录 | 原 business / public_finance / continuity / payment_record；保持企业范围 |
| 职位用工 | 招聘原因、签约责任、变动边界、初期考核 | 原 hiring_reason / contract / role_change / probation_rules；保持岗位范围 |

公共 UserProfile / SearchIntent 的 `1.0.0` 五条件不改字段含义：城市、最低固定月薪、销售指标、出差、外包接受与否。细题 must 不自动改这些条件。附表结构版本 `a-needs-refinement/1`、题库版本 `a-needs-refinement-20261013-1`；新细化记录使用 `a-taxonomy-2`，原导出兼容 `a-taxonomy-1`。旧确认快照不重算、不补题、不改 checksum；原配送 fixture 的导入已回归验证。

## 失败与修复记录

- 受限进程的系统 TEMP 持久化替换遭 EPERM；纯规则可过，历史 HTTP 无法正常保存。改用隔离目录并在正常本机权限下验证，正式 A 全部适用项目通过。没有为了绕过测试改掉原子保存。
- 旧浏览器脚本依赖已删除的 JSON 下载按钮；改为真实 Next 页面及 `/view`，为 standalone 同一服务补了 `/view` 兼容读取。
- Next 验收进程在受限环境无法读取工作路径；正常本机权限运行。最初 dev 自动改写共享类型配置，最终改成独立验收宿主；最初路由 junction 导致404，改成复制相同公开路由、共享实际模块源码。最终运行不写其他窗口的构建与持久数据。
- 细化原始数据的结构／题库版本早期接线不同步，正式集成失败后已统一并复测。
- 新目录标签最初无 B 检索映射，已补齐及回归；不能仅有 UI 标签而不能检索。
- 首次题页截图等到了结果页同名标题，改为等待题页 h2 并完整复测，最终截图实际查看。失败产物保留在忽略测试目录。

## 回退及实际限制

`A_NEEDS_REFINEMENT_ENABLED=false` 并重启服务，会使新填写沿用原七主题基础题；已确认细化快照仍可读取。原未知快捷入口保持原开关。公共契约、原始企业库、已有 C 报告与 V2 路径保留。

本轮完成的是更具体的本人声明需求采集和真实交接。新的具体安排尚没有经过认证的自动语义达标判定，C 明确保留未知并提出核实问题；检索关键词也是方向线索，不能据此断言匹配准确率。通勤上限、工作环境、资格／技能等未在当前五条件与28调查明细内的新维度不偷偷添加或推断。后续收益应通过真实用户试填、纠正率与招聘方逐项答复验证。

本机验收入口：`http://127.0.0.1:3260/profile?new=1`；从新窗口使用自己的会话填写。只监听本机、调查／模型关闭、使用独立 A 与报告目录；未合并 main 或生产部署。
