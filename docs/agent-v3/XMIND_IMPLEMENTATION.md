本机启动与回退：

1. 在本分支项目根目录按README安装Node/Python依赖，确认Git LFS企业库已展开；.venv为本项目依赖环境。
2. 默认V3关闭。本机开发时，在当前终端设置 RESEARCH_AGENT_ENABLED=true、RESEARCH_AGENT_V3_ENABLED=true、RESEARCH_AGENT_V3_MODEL_ENABLED=false，再启动 npm run dev 或优化构建后的 npm run start。模型不开启仍可处理已有正文。
3. 打开 /xmind：按公司名称查只读候选，粘贴主动提供文字，选择准确候选后进入公司探索报告；刷新后可从“我的公司建档历史”重开。此入口无A侧写时不猜个人底线、不造岗位。公开 /api/integration/xmind 返回441节点和13关系线及接入状态。
4. 个人需求使用 /profile→原B候选→原C。/reviews/:reportId 可以记录待复核任务，并产生新归档；旧报告不变。受控PDF可使用原B材料入口；公司API也接受本会话材料ID。
5. V3设置false并重启即回到已有调查路径；旧归档仍可读。新爬虫、OCR和平台授权另行接入。
6. 正式新增测试接入 npm test、npm run test:agent、npm run test:v3；HTTP/Chrome/关闭回退脚本为 scripts/validate-xmind-*.mjs。真实材料脚本需要本机先前取得的公开原件，缺少时会失败，不能当fixture通过。

此版本是可运行流程与可解释规则实现；未实现的语义模型、OCR、专用平台与真实群聊验证仍是实际缺口，不能称XMind全部能力完成。
