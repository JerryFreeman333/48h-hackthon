# Agent v2：实际实现

版本：`agent-v2.1`；解析规则 `xray-parser-2`；解释规则 `xray-evidence-rules-5`。公共契约仍为 1.0.0。v2 是有预算的确定性渠道适配器，不是四个独立模型进程。

## 网站调用链

`/research` → `POST /api/integration/research` → 原有 `research-jobs` → `demo-flow.runDatabase` → 只读数据库 CandidateBundle → `enrichWithAgent` 的 v2 开关 → `enrichWithV2` → JSON/Python 工具 → 证据校验/合入 → 原有 C 分析和报告归档 → `/flow/reports/:id`。

报告读取从归档的 `databaseSource.agentV2` 渲染，不在打开旧报告时重新联网。用户画像、岗位薪酬和已选候选仍由现有 A/B 流程负责；工具只收到公司记录 ID 和已确认关注点，收不到完整用户画像。

## 采集与证据

| 模块 | 实际职责 |

| `v2/parsers.py` | HTML 正文/段落/表格；PDFium 全文和物理页、印刷页；pdfplumber 有限候选页的表格及续表；无 OCR 时明确失败 |

原库 `.data/company-database/xray-v3-20261003.sqlite` 从未迁移或写入。新库为 `.data/research-agent/v2/evidence.sqlite`；原始 PDF 和压缩 HTML 保存于其 `raw/`。全文、页、表格及全部提取事实留库；传输最多 20 份文档、90 条事实、120 段引用、28 条解释和 100 条来源尝试，输出上限 1.5 MB。传输优先保留解释和比率输入、财务事实，再补比较用事实；报告显示保存总数与展示范围。

## 事实与解释边界

- `source_claim` 是来源陈述，`normalized_fact` 是按原文结构提取的字段；两者状态仍为 `source_claim`。跨源审查状态始终 `unresolved`，不因预算耗尽通过。
- 数字必须来自可定位的表格单元格；无法识别单位、币种或列期间时不提取。员工表只有明确报告期与单一数量列时才提取，统计口径未知仍保留未知。
- 资产负债率仅在同一材料、主体、期间、币种、单位和合并/母公司范围一致，且分母大于零时计算；保存公式和输入 ID。前端不输出投资评分。
- 栏目列表、招聘站导航、没有断言的“工资待遇/诉讼信息”以及“自主研发”不会作为员工待遇、事件或精神空间事实。
- 风险线索保留类别、原句中的主体/日期/金额、事件阶段与引用；缺失不补全。普通提及或标准条文仍可能需要人工语义复查，不能当已发生事件。
- 采购计划、招标、中标、合同、验收分别保存；“福利已交付”和人均金额固定未知。
- 显式来源岗位、城市、部门、经历时间单独保存；它们不自动映射为用户应聘岗位。所有新增公共证据仍为公司范围、`jobId=null`、`verification=unverified`。
- `mental_space` 单独记录，兼容映射至原文化板块；旧 `growth` 继续表示晋升与成长，问卷和公共契约没有改义。

置信度是透明规则等级：有明确表格口径或取得正文的来源陈述一般为中；未知统计口径、索引摘要、匿名社区经历为低。本版不自动赋高置信度，也不以搜索结果数提升等级；未全面实现时效衰减和跨源置信度提升。

## 去重、重试与恢复

材料 ID 使用主体及归一化正文哈希和访问模式；事实 ID 加规则版本。相同内容重采不会新增原始材料，原采集时间保留。独立来源按相同 canonical URL、内容哈希或明确原文链接做传递合并；无法识别的改写转载仍是限制。正文到手后当前快照去掉同网址的摘要副本。

任务键包含主体、关注点范围、数据库指纹、渠道查询、解析/规则版本和补查轮数。24 小时缓存只跳过完整成功阶段；失败渠道和摘要正文不会被当成已完成永久缓存。空结果不作为无风险证据。版本变化重新分析，既有归档报告不改写。

来源失败保留此前完成材料。Python 达到硬时限或异常结束后，服务端用 `read_company_checkpoint` 在最多 12 秒内只读同一任务证据，不重新联网，也不调用模型；结果仍为 partial。进程重启后的再次分析可继续未完成阶段。整个 Web 进程被结束时，需要用户再次分析来生成新报告；没有配置自动唤醒或后台守护。

v2 不调用模型、没有付费重试。原 MiniMax 路线保留在 v1 开关路径，现有模型边界测试通过；本轮未做真实 MiniMax 请求，因此不声称新的模型编排或计费幂等已经上线。

## 主要限制

正文识别与中文表格解析是有边界的规则，不覆盖扫描 PDF、所有复杂版式或全部语义；搜索页面变动可导致解析失败。集团关系未知时不向岗位下传待遇。没有登录、评论全集、专有企业 API 或实时全网覆盖。本地磁盘资料库需要持久存储；无持久盘/无 Python 的部署环境不能直接运行本模块。
